# 本仓库改了什么

## 4.44.0.2611

**加解密**

- **纯托管实现，去掉外部依赖**：内置 aescrypt2（AES-256-CBC + HMAC-SHA256，8192 轮派生）与 AES-256-GCM（走系统 CNG/bcrypt，支持 16 字节 nonce），不再需要外置 `aescrypt2.exe` 和 `libmbedtls.dll`。
- **修复 $4 容器首次打开必然失败**：启动时把 $4 密钥状态初始化为「默认槽 (1,2) + $2 静态钥匙」。上游没有这一步，首次打开 `03` 容器会在内部数组拷贝处越界，异常被外层 Catch 吞成「文件打开失败」，表现为「先操作点别的再开就好了」。
- **修复 $4 加密的密钥槽错配**：加密前统一归位到默认槽 (1,2)。上游在解过 `(10001,1)` 这类文件后，"密钥槽"会被改写成 `(10001,1)` 而口令仍是默认 $2 钥匙，再加密就写出设备解不开的文件。
- **新增 $2 静态容器（`01`）产出**：配合「压缩」复选项，可产出 `01`（静态钥匙）与 `02`（动态钥匙，原版已有）两种容器；下载配置包同样支持。
- **$3 无需密钥库也能解**：库里取不到对应 (Domain, Key) 时先试内置主密钥，解得像正常文本才采用，否则仍回退到弹窗手输。

**界面**

- 模式行重做：「板信息版本下拉 + Vx + $1 + $2 + $3 + $4 + 压缩 + 下载」。V3~V6 收进下拉，只用于 `hw_boardinfo`；`$3` 只解不产。
- 查找/替换窗口改为常驻非模态，支持「上一个 / 下一个 / 替换 / 全部替换」，默认忽略大小写（`Ctrl+F` / `Ctrl+H`）。
- 存不出对应落盘形态的组合（`$3`、`$4` + 非 XML 等）会提前拦截并说明原因，不再写出半截文件。
- 去掉对 `aescrypt2.exe` / `libmbedtls.dll` 的启动校验，缺文件不再拦。

**其他**

- 版本号 `4.44.0.2611`（第 4 段 `2611` = 2026 年 11 月，界面显示为 `4.44.0 (2026.11)`）。
- `MainUI` 拆分为 `MainUI.Crypto.vb` / `.Config.vb` / `.Save.vb` / `.Ui.vb` 四个分部文件，方法体逐行保留。
- 项目文件从 `HW Dollar4/` 子目录上移到仓库根目录；新增 `.editorconfig`；工程开启 `Option Strict On`；`.gitignore` 忽略 `.idea/`。
- 加密核心 `HwAescrypt2.vb` / `HwGcm.vb` 自带在仓库内，clone 后无需其他仓库即可编译。

# 软件功能

- 支持华为光终端 $1、$2、$3、$4 方式字符串解密。
- 支持华为光终端 $1、$2、$4 方式字符串加密。
- 支持使用 $2、$4 方式加密、解密 hw_boardinfo 文件，并生成哈希校验文件。
- 支持使用 $4 方式加密华为光终端 XML 格式配置文件，并生成哈希校验文件。
- 支持使用默认 AES 密钥、$2 动态密钥和 $4 方式解密华为光终端 XML、CFG 格式配置文件。
- 支持使用以上方式加密、解密下载配置文件。
- 支持产出 $2 静态（`01`）与动态（`02`）容器。
- 支持使用 KSF(v2) 文件自动搜索 UnVisible（一机一密）密钥。
- 支持批量显示 KSF(v2) 文件中的 Master Key。
- 支持单项匹配文本查找与替换。

# 系统要求

- Windows 10 及以上版本 64 位操作系统。
- Microsoft .NET Framework 4.7.2 及以上版本。

# 软件限制

⚠️ 用户需自主提供 $3、$4 方式数据解密 UnVisible（一机一密）密钥。

⚠️ 不支持 $3 方式数据加密。

⚠️ 不支持保存 CFG 格式配置文件。

# 构建

- 用 Visual Studio 2019 及以上打开 `HW Dollar4.sln`，选择 Release 构建即可，无需任何外部原生库。
- 纯命令行构建需要先用 `ResGen.exe` 把各窗体的 `.resx` 转成 `.resources`（资源名必须为 `HW_Dollar4.<窗体名>.resources`），再用 `vbc` 编译并逐个 `/resource:` 嵌入。
